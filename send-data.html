HOW THIS WORKS

Your file is filtered in this browser first

The page does not upload your Timeline file. It reads the file locally, keeps vehicle observations with reasonable accuracy, removes unrelated records, trims journey endpoints, rounds coordinates and times, and creates a new file for you to review. You decide whether to send that prepared file later.

Removed:
Wi-Fi scans, place visits, profile fields, and unrelated activity.
Filtered:
Low-accuracy points, duplicate timestamps, long gaps, and impossible jumps.
Coarsened:
Coordinates are rounded to about 100 metres and times to 15-minute buckets.
Excluded:
The first and last points of each usable run are removed to reduce endpoint exposure.

Only the prepared file can be emailed. The raw Timeline file stays in this browser. The button downloads the prepared JSON and opens a draft addressed to the project; attach the file and send it yourself.
